# Telegram Bot for Document Services

Telegram-бот для автоматизации приема заказов на оформление документов (Санэпид, BHP, PESEL, справки и др.).

## Возможности

- 📋 Выбор типа документа из списка шаблонов
- 📝 Динамический опросник полей для каждого документа
- 🛒 Корзина с возможностью добавления нескольких документов
- 🚚 Доставка InPost (данные для пачкомата)
- 💳 Выбор способа оплаты (Blik, Гривна, USDT)
- 📤 Отправка заказов менеджерам (маршрутизация по типу документа)
- ⚡ Режим "Постоянный клиент" для быстрых заказов
- 🆘 Кнопка "Связь с менеджером"
- 📦 Отправка трек-номера и готовых документов клиентам

## Структура проекта

```
bot/
├── main.py                 # Точка входа
├── config.py               # Конфиги, токены, ID чатов
├── db/
│   ├── models.py           # SQLAlchemy модели
│   └── crud.py            # Работа с БД
├── fsm/
│   └── states.py          # Состояния FSM
├── handlers/
│   ├── start.py           # /start, меню
│   ├── order.py           # Основной заказ
│   ├── fast_order.py      # Постоянный клиент
│   └── admin.py          # Для менеджера
├── templates/
│   └── documents.py       # Шаблоны документов
├── utils/
│   └── router.py          # Маршрутизация заказов
└── keyboards/
    └── buttons.py         # Inline клавиатуры
```

## Установка

1. Клонируйте репозиторий
2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Настройте `.env` файл (скопируйте из `.env.example`)
4. Запустите бота:
   ```
   python main.py
   ```

## Настройка .env

```env
BOT_TOKEN=your_bot_token_here
ADMIN_USERNAME=admin
```
